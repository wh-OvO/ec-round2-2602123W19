## 1. 五条铁律

### 铁律 1：动手前先读本文件的 §2（谁负责什么）和 §6（未提交改动）

```powershell

```

`git status` 里出现你**不认识**的 `M` 文件 → 先读 §6，那可能是别的会话正在做的活儿。
看不懂就先问用户，**不要直接覆盖**。

### 铁律 2：git 操作只碰自己的文件

| 允许 | 禁止 | 为什么 |
|---|---|---|
| `git add Core/Src/我改的那个.c` | `git add -A` / `git add .` | 会把别人未完成的半成品一起提交 |
| `git commit -m "..."` | `git reset --hard` | 直接抹掉别人的工作 |
| `git diff <文件>` | `git checkout -- <文件>` | **用户的源码里有手写标注，见铁律 3** |
| `git stash`（先确认没别人的东西） | `git commit --amend` / `git rebase` | 改写已有的提交历史 |

### 铁律 3：这四个文件里有**用户手写的学习标注**，永久禁止整文件覆盖

用户在自学 STM32，在源码里加了自己的注释，这些**丢了就找不回来**：

| 文件 | 标注长什么样 |
|---|---|
| `Core/Inc/arm_cfg.h` | `#菜单的意思#`、`#时钟#`、`#标准整数类型#` |
| `Core/Src/arm_pwm.c` | `#语法糖标签#`、`/* #72MHz / (PSC + 1) = 2MHz ... # */` |
| `Core/Src/main.c` | `//6个函数声明`、`//保证是C 编译器编译...`、`//头文件外部链接` |
| `Core/Inc/arm_pwm.h` | 同上 |

**只允许用 `edit` 做局部字符串替换；禁止 `write` 整文件重写，禁止 `git checkout`。**

### 铁律 4：**`plan.md` 同时被多个会话写，是正常的**

这份文件是**共享板**，不是任何会话独占的。你读它、改它的那几分钟里，别的会话很可能也在改同一段。

- **发现"刚刚被人改过"是正常现象**，不是冲突 —— 先看它新增了什么，再动你自己的
- 用 `edit` 做**局部替换**，**禁止 `write` 整文件重写**（会把别人这一轮新增的整段抹掉）
- 标题行的「最后更新」如果已被别人改过，**保留他写的内容、在后面追加你的**，不要整行替换
- 两个会话改到同一段、`edit` 报 `old_string was not found` → **重新读一遍再改**，不要绕过、不要放弃
- 会话之间**不打招呼就动别人的段落**是不可接受的；动别人负责的代码前先在 §8 留一句

### 铁律 5：**改动走分支，审完再合并**

**并发改动是常态**，所以有风险或涉及面大的改动都留在分支上，等别的会话审完再进 `main`。

## 4. 已定案的设计决定 —— **不要翻案，先问用户**

下面这些是反复讨论后定下来的，后来的会话如果觉得"应该改成另一种"，**先在回复里说明理由并等用户点头**，不要自己动手改：

| 决定 | 理由 |
|---|---|
| **主控用 Blue Pill；野火双 USB 板停用** | 野火板 3.3 V 轨实测 4.63 V，超过绝对最大值。TIM2 全重映射引脚不变；舵机由独立 12 V→buck→5 V 供电并与 MCU 共地，传感器只从 Blue Pill 3.3 V 取电 |
| **只有一个脉宽区间：标定表端点 + 硬件边界 500/2500** | 不再保留 600/2400“安全窗”；角度先钳位，脉宽天然落在表内。J4 自身标定 1430/1530，防止堵转 |
| **运行时日志只走 USART1；CDC 平时只跑二进制协议** | `proto_link.c` 独占 CDC。唯一例外是“按住 PA0 上电”的 5 s 启动窗口：此时可输出 ASCII 文本，超时自动回协议模式；文本绝不能进运行中的协议流 |
| **插补器留在 `proto_app.c`；5 ms 插补、20 ms 上报** | 与协议状态/目标强耦合；5 ms 满足 200 Hz，20 ms 满足 50 Hz 状态帧 |
| **J1 = 360° 连续舵机 + AS5600 + PID 闭环** | 连续舵机没有位置反馈，必须外挂编码器；J1 行程是一条弧（−180~+145°），误差直接相减，不绕 ±180 |
| **0x20 与 0x34 越限语义不同** | 0x20 按 T3 钳位后执行；0x34 直接拒绝并回 0x05，不能把不可达目标钳位后偷偷执行 |
| **传感器/急停安全态保持当前脉宽，不停止 PWM** | SG90 没有使能脚，停脉冲会失去保持力矩；MPU 丢线停插补并 hold，恢复后必须收到新 0x20 才继续 |
| **I²C1 保持 400 kHz** | 任务书与学长要求；长杜邦线 NACK 用短排线/加强上拉解决，不靠降速掩盖。速率唯一权威是 `main.c` 的 `ARM_I2C1_CLOCK_HZ` |
| **`arm_pwm.c` 是纯执行层，`arm_pid.c` 是独立静态库** | PWM 层不得出现 I²C/故障处理；PID 只依赖自身接口，便于 PC 单测与复用 |
| **A1 验收走 `c2s → ccs → scs`** | 0x34 先把笛卡尔坐标变球坐标，再经 CCS 求关节角、由 SCS 出口校验；三库零互相依赖 |

### 6.5.2 换板踩到的坑：CubeMX 用有损编码重写了带中文注释的文件

**现象**：GENERATE CODE 之后 `main.c` / `usbd_cdc_if.c` 变成**非法 UTF-8**，编辑器读不了。

**根因**：CubeMX 重新生成这两个文件时用系统代码页（GBK）回写，把三字节汉字的
**最后一个字节写成了 `?`（0x3F）**。因为三字节变三字节，**文件大小一个字节都没变**，
所以 `git diff` 只看得到内容变化，看不出"编码坏了"。

**规模**：`main.c` **59 行 / 131 个字**，`usbd_cdc_if.c` **4 行**。`main.c` 里全是用户
手写的教学标注，不能 `git checkout` 了事。

**修法**（已做完，脚本用完即删）：拿 `git HEAD`（完好的 UTF-8）逐行比对，
**ASCII 骨架必须逐字节相同**、非 ASCII 字符允许"原样 或 被 1~3 个替换符顶掉"，
匹配上才把整行换回 HEAD 版本。这样 CubeMX 真实改过的代码行不会被误覆盖。

**下次 GENERATE CODE 会重演。** 判据一条就够：

```powershell
try { [void][Text.UTF8Encoding]::new($false,$true).GetString($b); "OK" } catch { "坏了：$($_.Exception.Message)" }
```

### 6.6 当前 J1 底座闭环与标定口径

J1 当前已是 **360° 连续舵机 + AS5600 + PID 闭环**（`.kind = ARM_JOINT_VEL`），不是等待翻模式的占位状态。

**现行几何与坐标**

- 行程：`deg_min=-180`、`deg_max=+145`、`deg_home=0`；`CENTER=(deg_min+deg_max)/2=-17.5`。
- 换算：`机械角 = wrap180(SIGN × (raw − ZERO)) × SCALE + CENTER`。
- 当前标定：`ZERO=178.25`（机械角 CENTER 处的原始读数）、`SIGN=-1`、`SCALE=1.3333`、`RAW_SHIFT=0`。
- `raw_home=165.125` 是 home 处的实测原始角；由 `-(165.125−178.25)×1.3333−17.5≈0` 保证 home 读 0。
- 接缝：`CENTER ± 180×SCALE = −257.5 / +222.5`，离 −180/+145 两端各 77.5°。**接缝不是行程，误差里不做 wrap180。**
- PID：Kp 3.0、Ki 1.0、Kd 0；`U_MAX=200`、`U_KICK=35`、`I_MAX=25`、死区 1.5°、`DT=5 ms`、FF 关。

**读失败 / 限位的现行语义**

- `arm_joint_get_deg(0)` 读失败时返回 `s_base_last_deg`（最近一次成功角），不会返回目标角或 −100/−200 哨兵。
- `vel_tick()` 读失败当拍输出 `us_stop=1500` 并置 `s_base_fault`；连续 3 拍失败才清 PID，避免单拍 NACK 反复清积分。
- 实测角只夹到 `[deg_min−10°, deg_max+10°]`，保留限位外回拉方向；目标 145、实测 150 时误差 −5°，会往回拉。
- `s_base_fault` 置 bit4，**当前不会自动置 bit2，也不会冻结其它关节**；MPU6050 丢线才是停插补/hold + bit2+bit4。不要把两种故障混为一谈。

**安全与标定**

- `SIGN` 填反就是正反馈。任何重标定先把 `ARM_BASE_U_MAX_US` 临时降到 50，确认方向后恢复 **200**（不是旧手册的 300）。
- 改 `SCALE`、`deg_min/deg_max` 或 `CENTER` 后，必须重算 ZERO 与接缝，并验证 home≈0、两端≈−180/+145。
- AS5600 必须是径向磁铁，1~2 mm 气隙、中心同轴；VCC=3.3 V，禁止 5 V。
- AS5600 与 MPU6050 共用 `PB6/PB7`，地址不冲突；两块 4.7 kΩ 上拉并联约 2.35 kΩ。

> ⚠️ **旧标定手册不可直接照做**：`docs/AS5600_零点标定_实操.md` 仍写 home=90/CENTER=90/±170/U_MAX=300，属于旧坐标系。重标前先按本节与 `arm_cfg.h` 改写手册；现行常量已经填入，不要为了“等标定”再改回 POS 或旧行程。
