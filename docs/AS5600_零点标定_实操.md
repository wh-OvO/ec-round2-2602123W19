# AS5600 零点标定 · 实操手册（J1 底座闭环）

> 建立：2026-11-13 23:20　适用：`rm_arm` 当前代码（J1 `.kind = ARM_JOINT_VEL`，`ARM_BASE_U_MAX_US = 50`）
> 目的：把 `ARM_BASE_ENC_ZERO_DEG` / `ARM_BASE_ENC_SIGN` 这两个空填上，让底座闭环能正常工作。
> **这份是给手上操作的人看的**，每一步都写清"看什么、判什么、不对怎么办"。

---

## 0. 先搞清楚要标什么（30 秒）

AS5600 读出来的是 **0~360° 的原始角**，参考系是**磁铁自己**，跟机械角度毫无关系。
代码里要把它换算成机械角（home = 90°、下端 = 0°、上端 = 180°）：

```
机械角 = wrap180( SIGN × (原始角 − ZERO) ) + CENTER        CENTER = 90
```

所以只有两个未知数：

| 参数 | 含义 | 怎么定 |
|---|---|---|
| `ARM_BASE_ENC_ZERO_DEG` | 机械臂摆在 **home**（手臂朝正前方，机械角 = 90°）时，编码器读数是多少 | **手转到位，读一次数** |
| `ARM_BASE_ENC_SIGN` | 舵机往"正方向"转时，编码器读数**变大(+1)** 还是**变小(-1)** | **给一个小正向脉宽，看读数往哪边走** |

⚠️ **ZERO 必须在 home（90°）处读，不能在 0° 处读。** 差这一个 CENTER，上电后底座会全速转 90° 顶死。

---

## 1. 安全前提（这一节不能跳）

### 1.0 新焊的 DCDC 必须先量输出电压（**在插任何舵机之前**）

MP1584 这类降压模块出厂时电位器位置是**随机的**，输出可能是 3V，也可能是 **12V**。
12V 灌进 SG90 会立刻冒烟，灌进主控板会烧 3.3V LDO。

- [ ] **空载**（输出端什么都不接）给 12V 输入，万用表 DCV 量输出正负极
- [ ] 拧电位器，调到 **5.0 V**（4.9~5.1 都行，别超 5.2）
- [ ] 调好之后再插舵机；插上舵机后再量一次，**带载也不该掉到 4.5 V 以下**
- [ ] 顺手量一下纹波/发热：空载发热明显 = 电位器方向拧反或模块坏了

> 这一步做错，后面全白干。**先量电压，再插舵机。**

### 1.1 标定期间把 J1 舵机断电

项目的 `ARM_BASE_U_MAX_US` 已经临时降到 **50 µs**（正常 300），所以标定期间即使 SIGN 填错，
底座也只是**慢爬**而不是飞车。但慢爬一样能把手/线卷进去，所以：

- [ ] **把 J1 舵机的 5V 电源线拔掉**（信号线可以留着）。舵机不通电就绝对不会动，
      而 AS5600 是主控 3.3V 供的电，**照样能读**。
- [ ] 手边能一键断电（插排开关 / USB 拔掉）。
- [ ] 手臂周围清空，别让转盘扫到东西。

> **为什么必须拔舵机电源：上电瞬间闭环就已经在跑了。**
> `vel_tick()` 判断的是"这一路有没有被 `0x31` 接管"（`s_manual[]`），
> **不是**上位机显示的那个模式（`s_mode`）。所以哪怕上位机显示"手动"，
> 只要没发过 `0x31`，底座就会自己朝 `s_tgt_deg[0] = deg_home = 90°` 爬过去。
> 现在 ZERO 还是 0，这个"90°"落在哪儿是未知的 —— 最多可能转 180°。
> `U_MAX_US = 50` 把它限成约 100°/s（约 2 秒转完），但**它会动**。
> 拔了 5V 就绝对不会动。

> 拔舵机电源这件事，是本手册能"随便手转"的前提。**插着电手转 = 和舵机较劲，会烧舵机。**

## 2. 第 1 步：确认编码器活着

烧录当前代码，上电，连上位机，看 **0x10 状态帧**。

| 看哪里 | 正常 | 不正常 |
|---|---|---|
| 状态位 **bit4（I²C 失效）** | **不亮** | 亮 → 见 §7 故障表 A |
| **q1 角度值** | 是个 0~360 范围内的数 | 恒等于 90 → 编码器没读到，读的是"目标值兜底" |

**关键判据：手转底座，q1 会不会跟着变？**

- 手转，q1 平滑地变 → ✅ 编码器通了，进第 3 步
- 手转，q1 纹丝不动 / 跳 0 和 360 → ❌ 见 §7 故障表 A / B

> 为什么能在这里看到编码器值：J1 已经是 `ARM_JOINT_VEL`，`arm_joint_get_deg(0)` 走的是
> `base_read_deg()` → `as5600_read_deg()`。位置型关节返回的是 CCR 反算值，看不见编码器。

---

## 3. 第 2 步：定 ZERO

此时 `ARM_BASE_ENC_ZERO_DEG = 0`、`SIGN = +1`，所以上位机看到的 q1 就是：

```
q1 = wrap180(原始角) + 90
```

**操作：**

1. 手把底座转到 **home 位**：手臂朝正前方，也就是你认定的"机械角 90°"那个姿态。
   转到位后**别松手**，或者垫个东西让它别动。
2. 读 q1，记下来，设为 **X**。
3. **ZERO = (X − 90) 取模 360**，即：

   | X 的范围 | ZERO 填 |
   |---|---|
   | X ≥ 90 | `X − 90` |
   | X < 90 | `X + 270` |

   例：home 处读到 q1 = 132.4 → ZERO = 42.4
   　　读到 q1 = −18.6 → ZERO = 251.4

4. 把 ZERO 写进 `arm_cfg.h` 的 `ARM_BASE_ENC_ZERO_DEG`（`SIGN` 先别动），重新编译烧录。

**验收**：上电后**不动手**，q1 应该就在 **≈90**（差几度正常，D 有死区）。
如果 q1 变成 0 或 180 左右 —— 算错了，回第 3 步重来（大概率是加减 90 弄反了）。

---

## 4. 第 3 步：定 SIGN

ZERO 对了之后，只剩下"哪边是正方向"。

**操作**（这次舵机要通电）：

1. 把 J1 舵机 5V 插回去。**手放在总电源上。**
2. 上位机发 **`0x31`**：舵机号 = `0`（J1）、脉宽 = **`1550`**、flags 带 **EN**（开输出）。
   - 1550 比停转点 1500 高 50µs，实测约 100°/s，慢转，看得清。
   - 发完这一帧，J1 会进入**手动模式**（`arm_joint_set_manual`），闭环让开，只认你给的脉宽。
3. 盯着 q1 看它往哪边走：

   | 现象 | SIGN 填 |
   |---|---|
   | q1 **变大**（90 → 100 → 110 …） | **`+1.0f`** |
   | q1 **变小**（90 → 80 → 70 …） | **`-1.0f`** |

4. **立刻发 `0x31` 脉宽 `1500`** 让它停（别等它转到限位）。
5. 把 SIGN 写进 `arm_cfg.h`，重新编译烧录。

> 为什么这样能定符号：正脉宽 = 舵机的"正方向" = 机械角增大方向。
> 编码器读数跟着变大，说明两者同向（+1）；反过来就是反向（−1）。

---

## 5. 第 4 步：复核

⚠️ **复核时舵机必须还是断着电的**（或者用 `0x31` 接管成手动）。
插着电、闭环活着的时候用手去推 = 跟闭环打架：你推过去，它自己拉回来，读数永远在 90 附近。

| 检查 | 期望 | 不对说明 |
|---|---|---|
| home 处 q1 | **≈90** | ZERO 错 |
| 手推到行程一端 | **≈0** | ZERO 或 SIGN 错 |
| 手推到另一端 | **≈180** | 同上 |
| 全程 | **不允许出现负数** | SIGN 反了（正反馈） |
| 手转一整圈 | 0→180 连续，**没有跳变** | 接缝落在行程里 → ZERO 取样点错 |

---

## 6. 第 5 步：收尾

1. `arm_cfg.h`：`ARM_BASE_U_MAX_US` 从 **50 → 300**。
2. 重新编译烧录。
3. 退出手动：发 `0x20`（目标角度）或 `0x21 = 1`（自动），闭环接管。
4. 给一个小目标（比如 +5°），看它**慢慢靠近并停住**：
   - 停住不抖 → ✅ 标定完成，可以进 PID 整定
   - 往一个方向一直跑不停 → **SIGN 还是反的**，立刻断电，回第 4 步

> ⚠️ 纯 P（Ki=0）时**一定有稳态误差**：Kp = 3 µs/°，而舵机自带死区约 ±10 µs，
> 折算下来误差在 **±3~5° 内它根本不响应**。这是物理，不是 bug ——
> 要靠加 I 才能消掉。所以第 4 步看到"差 3° 停住"是**正常**的。

## 7. 故障表

### A. 状态位 bit4 亮 / q1 恒为 90（编码器没认出来）

`as5600_init()` 在读 **STATUS 寄存器 bit5（MD，磁铁检测）**，`MD = 0` 就直接判"不在线"。
按概率从高到低查：

| # | 原因 | 怎么确认 |
|---|---|---|
| 1 | **磁铁不是径向充磁** | 普通圆片磁铁（轴向充磁）完全没用。搜索词要写「径向充磁 圆片磁铁」 |
| 2 | **气隙太大**（>3 mm） | 磁铁离芯片正面 1~2 mm 最稳 |
| 3 | **没共地** / 模块接的是 5V | AS5600 必须 **3.3V**，且 GND 和主控共地 |
| 4 | **SDA/SCL 接反** | `PB6` = SCL、`PB7` = SDA |
| 5 | 上拉电阻没接 | 模块一般自带 4.7k；裸芯片要外接 |
| 6 | 地址不对 | 固定 `0x36`（7 位），DIR 脚接地 |

> `as5600_init()` **只在开机时调一次**。装好磁铁/改完线**必须重新上电**，热插拔无效。

### B. q1 在 0 和 360 之间来回跳

磁铁**偏心**或**倾斜**。同轴偏差要 ≤0.5 mm，磁铁面要平行于芯片。
手转一圈看读数是否单调 —— 有回头就是装歪了。

### C. 给了 1550 但舵机不转

- 死区：这台 SG90 的死区约 1490~1520，1550 应该出得来；给 **1600** 再试。
- 检查 `0x31` 的 **flags 有没有带 EN 位**（不带 = 输出关断，写了也不发波）。
- 万用表量 `PA15`：`V = 3.3 × 脉宽µs / 20000`，1550µs ≈ 0.256 V。

### D. 一转就冲到限位停住（q1 卡在 0 或 180）

**SIGN 反了**（正反馈）。立刻断电，把 SIGN 取反，重烧。
